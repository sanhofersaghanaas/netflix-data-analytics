
# Netflix Data Analytics Project

## Project Overview
This project explores Netflix movies and TV shows
to identify content trends and patterns using Python.

## Objectives
- Compare movies and TV shows.
- Analyze content release-year trends.
- Identify top countries and genres.
- Explore content rating distribution.
- Generate insights through data visualization.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Load the Netflix dataset.
2. Inspect and clean the data.
3. Handle duplicate records and missing values.
4. Perform exploratory data analysis (EDA).
5. Create charts and visualizations.
6. Summarize findings.

## Visualizations
- Movies vs TV Shows
- Content released by year
- Top 10 countries
- Top 10 genres
- Content rating distribution

## Dataset
Netflix Movies and TV Shows dataset:

https://www.kaggle.com/datasets/shivamb/netflix-shows

## Project Files
- `Netflix_Data_Analysis.ipynb` — analysis notebook

## Key Findings
The notebook contains the analysis results,
visualizations, and findings derived from the dataset.

## Limitations
This project analyzes catalogue information.
It does not measure actual viewership or prove
the causes behind content release decisions.
